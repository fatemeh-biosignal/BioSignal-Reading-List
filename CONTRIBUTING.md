# Contributing to BioSignal

Thank you for your interest in contributing to the BioSignal project! 
This project aims to develop a low-power wearable ECG monitoring system using Compressive Sensing and TinyML.

## How to Contribute
1. **Fork the Repository:** Create your own copy of this project.
2. **Create a Branch:** Make a new branch for your feature or bug fix (e.g., `feature/new-filter`).
3. **Commit Your Changes:** Write clear and descriptive commit messages.
4. **Push to Your Branch:** Push your changes to your forked repository.
5. **Open a Pull Request:** Submit a pull request describing your changes.

## Code Style Guidelines
- **Python:** Follow PEP 8 guidelines.
- **C:** Use clear variable names and add comments for complex logic.
- **Documentation:** Update the `README.md` or relevant `.md` files if you add new features.

## Reporting Issues
If you find a bug or have a suggestion, please open an Issue in the GitHub repository. Describe the problem clearly and include steps to reproduce it.

## Contact
For any questions, feel free to reach out to the project maintainer (Fatemeh Karimi) via GitHub.
