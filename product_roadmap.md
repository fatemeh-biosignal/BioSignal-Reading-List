# Product Roadmap

This document outlines the planned features and releases for the BioSignal wearable ECG device.

## Version 1.0 (MVP - Minimum Viable Product) - Q3 2027
- **Focus:** Proving the core concept.
- **Features:**
  - Hardware: Breadboard prototype using AD8232 and STM32.
  - Software: Basic filtering and Compressive Sensing (CS) compression.
  - AI: Random Forest classifier for Arrhythmia detection.
  - App: Basic GUI dashboard on a PC.

## Version 2.0 (Wearable Prototype) - Q4 2027
- **Focus:** Portability and patient comfort.
- **Features:**
  - Hardware: Custom PCB design (smaller size).
  - Software: Optimized C code for low-power operation.
  - App: Mobile app (Android/iOS) connected via Bluetooth (BLE).
  - Battery: Li-Po battery with 3-day life.

## Version 3.0 (Commercial Product) - 2028
- **Focus:** Medical certification and market launch.
- **Features:**
  - Hardware: Water-resistant, biocompatible patch.
  - AI: Advanced Neural Network (1D-CNN) for higher accuracy.
  - App: Cloud sync for doctors and emergency alerts.
  - Regulatory: CE/FDA approval.
