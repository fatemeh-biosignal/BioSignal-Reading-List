# Model Card: TinyML Arrhythmia Classifier

This document provides details about the Machine Learning model used in the BioSignal project.

## 1. Model Details
- **Model Type:** Random Forest Classifier.
- **Developed by:** Fatemeh Karimi.
- **Framework:** Scikit-Learn (Python).
- **Task:** Binary Classification (Normal Heartbeat vs. Arrhythmia).

## 2. Intended Use
- **Primary Use:** On-device detection of arrhythmias in a wearable ECG patch.
- **Target Users:** Patients with a history of heart disease and healthcare providers.
- **Out-of-Scope Use:** This model is NOT a substitute for a professional medical diagnosis. It is a screening tool.

## 3. Training Data
- **Current State:** The model is currently trained on synthetic ECG data generated in `tinyml_classifier.py`.
- **Next Step:** Future versions will be trained on the MIT-BIH Arrhythmia Database (real clinical data).

## 4. Limitations
- **Synthetic Data Bias:** Since the current data is synthetic, the model's real-world accuracy is not yet validated.
- **Single-Lead ECG:** The model only analyzes single-lead ECG, which might miss certain types of arrhythmias.

## 5. Ethical Considerations
- **Privacy:** Data never leaves the device (no cloud inference).
- **Human-in-the-Loop:** Any alert generated by the model must be confirmed by a doctor before medical action is taken.
