# Project Visuals

This file will contain the plots and visual results generated by the Python scripts in this repository.

## Planned Visuals:
1. **Raw vs. Filtered ECG:** A plot showing the effect of the Moving Average filter on removing noise from the ECG signal.
2. **Compressed Sensing:** A scatter plot showing the 30% of samples kept (red dots) against the original signal (blue line).
3. **OMP Reconstruction:** A comparison plot between the original signal and the signal reconstructed using the OMP algorithm.
4. **MSE Comparison:** A bar chart comparing the Mean Squared Error (MSE) of Linear Interpolation vs. OMP.

*(Note: To see these plots, you can run the Python scripts in this repository locally.)*
