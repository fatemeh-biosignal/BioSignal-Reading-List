# پروژه BioSignal (نسخه فارسی)

به مخزن پژوهشی من خوش آمدید! من یک مهندس برق الکترونیک هستم که در نقطه تلاقی الکترونیک و پردازش سیگنال‌های زیستی (Biomedical Signal Processing) فعالیت می‌کنم.

## 🎯 تمرکز پروژه
طراحی یک **سیستم پایش ECG پوشیدنی کم‌توان** با استفاده از **سنسینگ فشرده (Compressive Sensing)** و **هوش مصنوعی سبک (TinyML)** برای تشخیص آریتمی قلبی.
