## [1.0.0] - 2026-11-06
### Added
- **Core Algorithms:** Python scripts for signal generation (`ecg_simulation.py`), filtering (`advanced_filtering.py`), and Compressive Sensing (`compressed_sensing_demo.py`, `omp_reconstruction.py`).
- **Machine Learning:** TinyML Random Forest classifier (`tinyml_classifier.py`) for arrhythmia detection.
- **Embedded C Code:** C implementation for microcontrollers (`embedded_c_code.c`).
- **GUI Dashboard:** Visual interface for demonstration (`gui_dashboard.py`).
- **Comprehensive Documentation:** Math model, system architecture (Mermaid), hardware specs, clinical safety, and business model.
- **Project Management:** License (MIT), Contributing guidelines, and Citation file (CFF).
