# Project Execution Plan & Budget

This document outlines the actionable steps, timeline, and estimated budget required to execute the BioSignal project.

## 1. Phase 1: Hardware Prototyping (Month 1-3)
- **Tasks:** Finalize schematic, design PCB in Altium, order components, assemble the prototype.
- **Budget:** 
  - PCB Manufacturing: $50
  - Components (STM32, AD8232, BLE, etc.): $100
  - Soldering Equipment & Tools: $50
- **Total Phase 1:** ~$200

## 2. Phase 2: Firmware & TinyML Deployment (Month 4-6)
- **Tasks:** Port Python algorithms to C, optimize TinyML model for STM32, test power consumption.
- **Budget:** 
  - ST-Link Programmer: $20
  - Multimeter/Oscilloscope (if not available): $100
- **Total Phase 2:** ~$120

## 3. Phase 3: Clinical Validation (Month 7-12)
- **Tasks:** Test on MIT-BIH dataset, conduct pilot study with 10 patients in a hospital.
- **Budget:**
  - Disposable Patch Materials: $100
  - Hospital Collaboration Fees (Ethical Approval, etc.): $500
- **Total Phase 3:** ~$600

## 4. Phase 4: Regulatory & Documentation (Month 13-15)
- **Tasks:** Prepare IRC application, write the final report for Khwarizmi, publish the ICEE paper.
- **Budget:**
  - Patent Attorney Consultation (if possible): $300
  - Conference Registration Fee: $200
- **Total Phase 4:** ~$500

## 5. Total Estimated Budget (15 Months)
- **Grand Total:** ~$1,420 (Approx. 850,000,000 IRR).
- **Funding Sources:** Khwarizmi Award prize, University grants, and personal investment.
