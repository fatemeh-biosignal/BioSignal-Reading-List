# Future Roadmap: From Simulation to Commercial Product

This document outlines the future phases of the project, moving from software simulation to a real-world wearable medical device.

## Phase 1: Software Simulation (Current)
- [x] Develop ECG signal processing algorithms (Filtering, Compressive Sensing).
- [x] Implement OMP and TinyML (Random Forest) models in Python.
- [x] Create the system architecture and hardware specifications.

## Phase 2: Hardware Prototyping (Next Step)
- [ ] Purchase components (AD8232, STM32/RP2350, BLE module).
- [ ] Design the PCB (Printed Circuit Board) for the wearable device.
- [ ] Port the Python algorithms to C/C++ for the microcontroller.
- [ ] Test the device on a bench with simulated signals.

## Phase 3: Clinical Validation
- [ ] Obtain ethical approval for a small clinical trial.
- [ ] Test the wearable device on 10-20 patients (comparing results with standard hospital ECG).
- [ ] Evaluate accuracy, latency, and battery life in real-world conditions.

## Phase 4: Commercialization & Startup
- [ ] Apply for a patent for the low-power CS-TinyML algorithm.
- [ ] Register the device with medical regulatory bodies (e.g., FDA, CE).
- [ ] Pitch the product to investors to launch a MedTech startup.
- [ ] Partner with hospitals for mass adoption.
