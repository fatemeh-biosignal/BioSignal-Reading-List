# User Feedback & Iteration Plan

This document outlines the strategy for collecting feedback from patients and doctors to continuously improve the BioSignal device after its release.

## 1. Feedback Collection Methods
- **In-App Surveys:** Monthly pop-up surveys in the mobile app asking patients about comfort, battery life, and ease of use.
- **Doctor Interviews:** Quarterly interviews with cardiologists using the system to understand their experience with the alert dashboard.
- **Crash & Bug Reports:** Automatic, anonymous error reporting (with user consent) to identify technical issues in the field.

## 2. Key Metrics (What we measure)
- **Usability:** System Usability Scale (SUS) score from patients.
- **Accuracy:** False Positive Rate (how often the device sends a false alarm) and False Negative Rate (how often it misses a real event).
- **Adherence:** How many days per month the patient actually wears the patch.

## 3. Iteration Cycle (Agile Development)
- We will adopt an **Agile methodology**, releasing firmware updates every 3 months.
- Major features (like adding a new sensor) will be released yearly based on user demand.

## 4. Feedback from Early Adopters (Beta Testers)
- During the clinical trial phase, we will recruit 20 beta testers (patients and doctors) to use the prototype for 1 month and provide detailed feedback.
