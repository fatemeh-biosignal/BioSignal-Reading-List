# Contributors Guide

Thank you for your interest in contributing to the BioSignal project! This guide outlines the standards and workflow for contributing to this repository.

## 1. Code Style
- **Python:** Follow PEP 8 guidelines. Use meaningful variable names and add docstrings to all functions.
- **C (Embedded):** Use clear variable names, avoid magic numbers, and add comments for hardware-specific logic.

## 2. Git Workflow
1. **Fork** the repository.
2. Create a **new branch** for your feature (e.g., `feature/advanced-filter`).
3. **Commit** your changes with clear messages.
4. **Push** to your branch and open a **Pull Request (PR)**.
5. Wait for the project maintainer (Fatemeh Karimi) to review and merge.

## 3. Documentation Standards
- If you add a new feature, you **must** update the relevant `.md` files (e.g., `README.md`, `srs.md`, or `methodology.md`).
- Add your name to the list below if you make a significant contribution.
