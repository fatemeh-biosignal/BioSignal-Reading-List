# Data Availability Statement

The data and materials used in this research are available as follows:

## 1. Source Code
The complete source code for the BioSignal project (including Python simulations, TinyML models, and embedded C code) is publicly available on GitHub at:
`https://github.com/fatemeh-biosignal/BioSignal-Reading-List`

## 2. Synthetic Data
The synthetic ECG data used for initial testing can be generated by running the script:
`python ecg_simulation.py`

## 3. Real Clinical Data
In future phases, the algorithms will be validated using the **MIT-BIH Arrhythmia Database**. This dataset is publicly available through PhysioNet at:
`https://physionet.org/content/mitdb/1.0.0/`

## 4. Patient Data Privacy
As stated in our Data Management Plan (DMP), raw patient data from the wearable device will not be shared publicly to protect patient privacy, in compliance with HIPAA and GDPR regulations.
